# Hello World from Hexo! 🚀

This is my first post powered by **Hexo** and deployed on **GitHub Pages**.

## What is Hexo?

Hexo is a fast, simple and powerful blog framework. You write posts in Markdown format, and Hexo generates a static website from your content.

## What is GitHub Pages?

GitHub Pages is a static site hosting service provided by GitHub. It allows you to host a website directly from your GitHub repository — completely free!

## Setting Up This Blog

Here's a quick overview of the setup process:

```bash
# Install Hexo CLI
npm install -g hexo-cli

# Initialize a new Hexo site
hexo init MyBlog
cd MyBlog

# Install dependencies
npm install

# Start local server
hexo server
```

Visit `http://localhost:4000` to preview your blog locally.

## Deploying to GitHub Pages

The site is automatically deployed via **GitHub Actions** — every time I push to the main branch, the site rebuilds and deploys automatically!
